# VPP 流量可视化引擎 (VPP Traffic Visualization Engine)\n\n## 📖 项目简介\n\n这是一个为VPP虚拟电厂实时监控仪表板设计的**流量渲染引擎**。它能够实时采集OVS镜像端口的网络流量，并在3D拓扑图中以粒子流的形式可视化展示，让观众能够\"看到\"VPP系统中各组件之间的数据流动。\n\n## 🎯 核心特性\n\n### 1. 实时流量采集\n- 从OVS镜像端口采集PCAP或JSON格式的网络流量\n- 解析报文信息（源IP、目的IP、协议、大小）\n- 采集延迟 < 100ms\n\n### 2. 智能流量分类\n- 自动识别控制指令和遥测数据\n- 计算流量强度（0.0-1.0）\n- 转化延迟 < 50ms\n\n### 3. 实时WebSocket推送\n- 将事件实时推送到前端\n- 支持多客户端连接\n- 推送延迟 < 100ms\n\n### 4. 3D拓扑可视化\n- 暗色背景的3D拓扑图\n- 显示VPP系统中的所有组件\n- 支持旋转、缩放、平移交互\n- 渲染帧率 >= 30fps（高流量）/ >= 60fps（正常）\n\n### 5. 粒子流动画\n- 代表报文的粒子在拓扑图中流动\n- 粒子大小与报文长度成正比\n- 粒子流速与报文频率成正比\n- 支持最多10000个粒子\n\n### 6. 流量类型区分\n- **控制指令**：暖色（红/橙/黄）+ 发光效果\n- **遥测数据**：冷色（蓝/青/绿）+ 半透明\n\n### 7. 交互功能\n- 点击组件查看详细信息\n- 悬停粒子流查看流量详情\n- 时间范围选择和流量回放\n- 暂停/继续/速度调整\n\n### 8. 数据导出\n- 截图导出（PNG）\n- 视频录制（MP4）\n- 数据导出（JSON/CSV）\n\n## 📊 系统架构\n\n```\n┌─────────────────────────────────────────────────────────────┐\n│                    后端采集层 (Backend)                      │\n│  OVS镜像端口 → 流量采集 → 事件队列 → 缓冲                   │\n└─────────────────────────────────────────────────────────────┘\n                              ↓\n┌─────────────────────────────────────────────────────────────┐\n│                  中间转化层 (Transformation)                 │\n│  流量分类 → 事件生成 → 强度计算 → WebSocket推送             │\n└─────────────────────────────────────────────────────────────┘\n                              ↓\n┌─────────────────────────────────────────────────────────────┐\n│                   前端渲染层 (Frontend)                      │\n│  WebSocket客户端 → 3D场景 → 粒子系统 → Three.js渲染        │\n└─────────────────────────────────────────────────────────────┘\n```\n\n## 🔧 技术栈\n\n### 后端\n- **Python 3.8+**\n- **Flask** - Web框架\n- **Flask-SocketIO** - WebSocket支持\n- **Scapy/dpkt** - 报文解析\n- **asyncio** - 异步处理\n\n### 前端\n- **HTML5/CSS3/JavaScript (ES6+)**\n- **Three.js** - 3D渲染\n- **WebSocket API** - 实时通信\n\n### 部署\n- **Docker** - 容器化\n- **Docker Compose** - 编排\n\n## 📈 性能指标\n\n| 指标 | 目标 |\n|------|------|\n| 流量采集延迟 | < 100ms |\n| 事件转化延迟 | < 50ms |\n| WebSocket推送延迟 | < 100ms |\n| 3D渲染帧率 | >= 30fps（高流量）/ >= 60fps（正常） |\n| 粒子数量限制 | <= 10000 |\n| 事件处理吞吐量 | >= 1000 events/sec |\n| CPU使用率 | < 50% |\n| 内存使用 | < 500MB |\n\n## 📋 需求覆盖\n\n本项目包含**10个主要需求**和**20个实现任务**：\n\n### 需求\n1.
