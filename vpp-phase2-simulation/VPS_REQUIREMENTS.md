## 🚀 快速部署

### 一行命令部署

```bash
# 下载并执行部署脚本
curl -fsSL https://raw.githubusercontent.com/your-org/vpp-phase2-simulation/main/deploy-vps.sh | sudo bash
```

### 手动部署 (5 分钟)

```bash
# 1. 连接到 VPS
ssh root@your-vps-ip

# 2. 更新系统
apt-get update && apt-get upgrade -y

# 3. 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh

# 4. 克隆项目
git clone https://github.com/your-org/vpp-phase2-simulation.git
cd vpp-phase2-simulation

# 5. 启动应用
docker-compose up -d

# 6. 验证
curl http://localhost:8080/health
```

## ⚠️ 常见问题

### Q: 最低配置能运行多久？
A: 最低配置 (1GB 内存) 可以稳定运行，但在高并发时可能出现性能问题。建议至少使用 2GB 内存的配置。

### Q: 需要多少存储空间？
A: 
- 应用本身: 2-5 GB
- 数据库: 取决于数据量，建议预留 20+ GB
- 日志: 建议预留 10+ GB
- 备份: 建议预留 10+ GB

### Q: 可以在 Windows VPS 上运行吗？
A: 可以，但需要安装 WSL2 (Windows Subsystem for Linux 2)。建议使用 Linux VPS。

### Q: 如何扩展配置？
A: 大多数云服务商支持在线升级 VPS 配置，无需停机。

### Q: 需要备份吗？
A: 强烈建议定期备份数据库。可以使用脚本自动备份到云存储。
