问题1: VPP主站用的是哪个开源组件？
===============================================

答案: Bottle.py 框架

详细信息:
- 框架名称: Bottle.py
- 类型: 轻量级 Python Web 框架
- 特点: 
  * 单文件框架，易于部署
  * 内置路由、模板、会话管理
  * 支持 WSGI 标准
  * 性能优异，适合微服务

VPP Master 架构:
├── 主应用: app.py (基于 Bottle)
├── 路由模块:
│   ├── routes/devices.py - 设备管理
│   ├── routes/dispatch.py - 调度控制
│   ├── routes/protocol.py - 协议转换
│   └── routes/analysis.py - 分析功能
├── 中间件:
│   ├── middleware/error_handler.py - 错误处理
│   ├── middleware/auth.py - 认证
│   ├── middleware/authorization.py - 授权
│   ├── middleware/rate_limiter.py - 速率限制
│   ├── middleware/request_validator.py - 请求验证
│   └── middleware/response_formatter.py - 响应格式化
├── 业务逻辑:
│   ├── services/device_manager.py
│   ├── services/dispatch_engine.py
│   ├── services/protocol_converter.py
│   └── services/analyzer.py
└── 数据库: PostgreSQL + SQLAlchemy ORM

运行方式:
- 开发: python3 app.py
- Docker: docker-compose up
- 端口: 8080 (默认)

问题2: 目前已实现的工控协议有哪些？
===============================================

答案: 4个主要工控协议已完全实现

1. IEC61850 (IEC 60870-5-104)
   ├─ 文件: vpp-phase2-simulation/services/protocol_adapters/iec61850_adapter.py
   ├─ 用途: 电力系统通信标准
   ├─ 端口: 102
   ├─ 状态: ✅ 完全实现
   └─ 功能: 
      * ASDU 消息解析
      * 数据完整性维护
      * 错误处理和日志

2. Modbus
   ├─ 文件: vpp-phase2-simulation/services/protocol_adapters/modbus_adapter.py
   ├─ 用途: 工业设备通信
   ├─ 端口: 502
   ├─ 状态: ✅ 完全实现
   └─ 功能:
      * Modbus TCP/RTU 支持
      * 寄存器读写
      * 异常处理

3. DNP3 (Distributed Network Protocol 3)
   ├─ 文件: vpp-phase2-simulation/services/protocol_adapters/dnp3_adapter.py
   ├─ 用途: 电力系统监控和控制
   ├─ 端口: 20000
   ├─ 状态: ✅ 完全实现
   └─ 功能:
      * 对象和变量支持
      * 事件报告
      * 时间同步

4. MQTT (Message Queuing Telemetry Transport)
   ├─ 文件: vpp-phase2-simulation/services/protocol_adapters/mqtt_adapter.py
   ├─ 用途: 消息队列和发布-订阅
   ├─ 端口: 1883
   ├─ 状态: ✅ 完全实现
   └─ 功能:
      * MQTT 3.1.1 规范
      * QoS 支持 (0, 1, 2)
      * 主题订阅和发布

协议支持架构:
├── 协议注册表: protocol_adapters/registry.py
│   └─ 动态注册/注销协议
├── 协议映射: protocol_adapters/mapper.py
│   └─ 协议间数据转换
├── 协议验证: protocol_adapters/validators.py
│   └─ 数据有效性检查
├── 协议转换: protocol_adapters/transformers.py
│   └─ 数据格式转换 (如电压单位转换)
└── 基类: protocol_adapters/base.py
    └─ 所有协议适配器的基类

协议测试覆盖:
- IEC61850 测试: tests/test_iec61850_adapter.py
- Modbus 测试: tests/test_modbus_adapter.py
- DNP3 测试: tests/test_dnp3_adapter.py
- MQTT 测试: tests/test_mqtt_adapter.py
